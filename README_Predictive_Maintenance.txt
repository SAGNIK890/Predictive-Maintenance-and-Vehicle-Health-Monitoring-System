AI/ML-Based Predictive Maintenance & Vehicle Health Monitoring
===============================================================

Project 1 — Module 3 Connectivity

Included:
1. Complete Google Colab notebook
2. Dataset link/reference
3. Project implementation using:
   - Logistic Regression
   - Random Forest
   - XGBoost
   - Feature importance / XAI
   - SHAP explanation
   - Failure probability
   - Vehicle health score
   - Maintenance alerts

Dataset:
https://huggingface.co/datasets/mukherjee78/predictive-maintenance-engine-data

Open the .ipynb file in Google Colab and use Runtime -> Run all.

Note:
The project brief mentions vibration, battery voltage, vehicle speed and operating hours.
The selected public dataset does not contain those fields, so the notebook uses only
the sensor columns actually available in the dataset.
